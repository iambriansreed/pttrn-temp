`pttrn-checkbox-group` and `pttrn-checkbox-group-item`: the CheckboxGroup as a form-associated Web Component. Each option is a `pttrn-checkbox-group-item` child; the group submits every checked value under its `name`, `select-all` adds the "All" checkbox (mixed while some options are checked), `required` blocks submission until an option is checked, and `label` with `helper-text` or `error-message` renders the CheckboxGroupField fieldset.
